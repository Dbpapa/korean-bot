# K-Drama & C-Drama Bot (Offline Version)

Telegram bot to search Korean and Chinese drama info from a local database.

## Commands
- `/start`
- `/drama <name>`

## How to Add More Dramas
Edit `dramas.json` and add more drama entries.

## Deployment (Koyeb)
1. Push to GitHub
2. Deploy Python app on Koyeb
3. Set `bot.py` as entry point
4. Add `BOT_TOKEN` in code or as a Koyeb environment variable
